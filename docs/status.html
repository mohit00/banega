Family app

What the household sees on the phone

Onboarding: family and pasand

Done

Splash, "Ghar mein kaun kaun hai?", per-member preferences and the Maharaj loading screen, matched to the prototype.

How to use
  1. Open the app and tap Apna ghar set karo.
  2. Tap Member jodo to add people, then tap a member.
  3. Pick diet, mirch level, needs and favourite cuisines, then Save.
  4. Tap {n} log · Aage badho to reach Home.

Home recommendations

Done

Slot tabs, "Maharaj ka pick", 8 ranked tiles with Perfect / Tweak / Nahi badges, max 2 per dish type, quick-ask chips.

How to use
  1. Switch Nashta / Lunch / Dinner at the top.
  2. Read the badge on each tile: Sabke liye, Sab · 2 tweak or 4/5 ke liye.
  3. Tap ADD to put a dish in today's menu.

Recipe detail

Done

Per-member fit, ingredients scaled to servings (salt and spices scale less, whistles stay fixed), steps, video link.

How to use
  1. Tap any tile or card.
  2. Check Kaun khayega for each person's verdict and reason.
  3. Use the servings stepper; quantities update.
  4. Tap Menu mein daalo or Video recipe.

Maharaj chat

Done

Ask in Hinglish, English or Hindi. Recipe cards appear first, then the reply. Rule parser scores 100% on the 112-query golden set.

How to use
  1. Tap the yellow chef button or the search bar on Home.
  2. Type "15 min mein nashta" or "Dadi ke liye Jain dinner", or tap a chip.
  3. Tap ADD on a card, or tap the card to open it.
Uses Claude when ANTHROPIC_API_KEY is set on the server; otherwise the rule parser and template replies. Small gap: follow-up chips from the server stay in Hinglish when the app is in English.

Admin panel

Done

Users, households, members, cooks, ingredients, staples, recipes with inline ingredients, swaps, config, menus, tickets, stock, ration, approvals, ratings, subscriptions.

How to use
  1. Run scripts\dev-servers.bat, then open http://127.0.0.1:8766/admin/login.
  2. Recipes: fill the form, add ingredient rows, upload a photo, then Reviewed → Publish. Publish refuses recipes with diet-policy violations.
  3. Use Card preview, Ticket board, Kitchen health and Maharaj golden set pages.
