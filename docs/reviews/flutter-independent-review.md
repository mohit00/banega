# Council independent review — Flutter app (Opus, 2026-09-26)

Verdict: **needs_changes** (blocking for a store release). UI, demo sandbox, copy, tokens, reduce-motion and the local engine are strong; the production path is not ready.

## Blockers
- **B1 No authentication.** `data/data_source.dart:25-37` Dio has no auth interceptor, no token storage, no OTP screens; 401 surfaces as raw DioException. Fix: AuthRepository (OTP start/verify), flutter_secure_storage, QueuedInterceptorsWrapper with single-flight refresh, 401 as its own error class incl. the offline queue.
- **B2 Any connection blip permanently swaps the real household for the demo family, writes included.** `data_source.dart:15-22` fallBackToDemo "for the session"; `api_repository.dart:64-75` treats receive/send timeouts (8 s) as connection errors; `kitchen_repositories.dart:133-138` putDishes/patchMenu fall back on writes; chat too (`api_chat_repository.dart:165-168`). Fix: remove runtime fallback from production; demo is an explicit sandbox; offline = error/offline state with retry; never route a write elsewhere; longer chat timeout.
- **B3 Offline write queue drops/loses cook writes.** `ticket_cache.dart:292-295` drops all non-connection errors (5xx/502/429/401); read-all-then-write race between add() `:261` and replay() `:296-297`; two replays run concurrently (today+tomorrow providers); replay only on rebuild, no connectivity/resume trigger. Fix: retry on 5xx/408/429, drop only on 409/412/422 and tell the user; serialise queue (drift, per-row delete); trigger via connectivity_plus + AppLifecycleState.resumed; show "Bheja nahi gaya" on rows.
- **B4 No persisted session/household/onboarding; every cold start is Splash.** `router.dart:29` no redirect; members in-memory only; `meProvider` swallows errors so a hired cook is not redirected. Fix: GoRouter.redirect startup gate over auth + /me + consent (unauth → OTP, no consent → consent, cook-only → /cook, else /home); cache /me.
- **B5 Members API not wired.** `members_controller.dart:304` hard-bound to DemoMembersRepository; `api_repository.dart:54-56` initialMembers returns demo in API mode; no POST/PUT/DELETE members; no name entry; no removal. Fix: ApiMembersRepository CRUD with optimistic updates; empty list + loading state, never placeholder people; name entry and removal.
- **B6 Billing stub live in API mode; debug controls in release.** `billing_adapter.dart:50-53` restoreToken returns 'demo-stub-purchase-token' and is POSTed in production; purchaseWeekly returns null; `settings_screen.dart:253` demo cook role switch unconditional; `/gallery` registered in release; release signed with debug keys. Fix: in_app_purchase behind the adapter returning null until wired; gate demo/gallery behind kDebugMode/flavour; release signing config.

## Majors
- **M1 Midnight rollover stale.** `home_providers.dart:241-245` planDateProvider reads clock once; slotProvider too. Fix: midnight/resume ticking clock provider.
- **M2 Timezone is device, not household.** `kitchen_models.dart:22-34`, `plan_controller.dart:172-175`. Fix: Household.timezone + timezone package.
- **M3 Idempotency keys per attempt, no in-flight guard.** `plan_controller.dart:194`, `kitchen_providers.dart:21-24,257`; `cook_ui.dart:43-84` no busy state → double POST. Fix: key per intent (resource id, version, target) kept until success/definitive rejection; disable buttons in flight.
- **M4 Cook TTS can stick on Pause; no lifecycle handling.** `cook_audio.dart:47-62` ignores setLanguage/speak status, no error/cancel handlers, no pause on app background. Fix: check isLanguageAvailable, show "Hindi awaaz install karein", register handlers, stop on paused.
- **M5 Health data shown by default (F-5.3-05).** `labels.dart:198-199`, `home_screen.dart:193-195`, `loading_screen.dart:70-71`, `chat_labels.dart:30`, `fit_engine.dart:254-259`. Fix: per-member showOnHome flag, diet-only header by default.
- **M6 English locale mostly untranslated** (222/528 values equal Hinglish; Hindi 248/528) incl. Splash/Family/Prefs; `locale_controller.dart:45` reads locale once. Fix: complete translations + CI check; didChangeLocales.
- **M7 Allergen picklist and kid flag have no UI** (F-5.2-03 Blocker). Fix: allergen multi-select + "Bachcha hai" toggle in Prefs.
- **M8 No push/device registration; caches not durable/bounded/scoped.** No FCM, no POST /v1/devices; SharedPreferences cache plaintext, never evicted, not cleared on delete, not per-user; thread messages not cached (`ticket_cache.dart:144-145`), queued messages widget-local (`ticket_thread_screen.dart:43,60`). Fix: firebase_messaging + devices; drift with scope/TTL/purge; cache messages.
- **M9 No 200% gate for family screens, no goldens.** `phase5_test.dart:316-318` excludes Home; BCta fixed 52 px maxLines 1 (`buttons.dart:36-58`); Splash thali collapses (`splash_screen.dart:55`); hero fixed 176. Fix: goldens at 390×844 and 2× for 8 screens; CTAs minHeight/2 lines.
- **M10 Errors fail open/swallowed.** `account_providers.dart:55-62` subscription null → not read-only; `kitchen_providers.dart:148-152` /me swallowed; `plan_controller.dart:106-108`; no crash reporting/logging. Fix: typed error states, crash reporter, structured logger with PII scrubbing; unknown subscription = unknown.
- **M11 Error envelope partly parsed; unknown status → "new".** `kitchen_models.dart:168-178` ignores message_en/hi and details.allowed; `:91` TicketStatus.fromWire defaults to fresh. Fix: parse details, localized message, `unknown` status with no actions.

## Minors
Video recipe ignores launchUrl false / no scheme allowlist (`recipe_detail_screen.dart:167-170`); delete account navigates on failure (`settings_screen.dart:240-246`) and purges nothing; demo link skips consent (`splash_screen.dart:75`); `members.first` on empty (`prefs_screen.dart:40`); thread input cleared before send (`ticket_thread_screen.dart:55-66`); no GoRouter errorBuilder, no intent filters; thali CustomPainter blur every frame on low-end (`thali_hero.dart:41-56`), no static thali for low-end; cook mode locked to Hindi (`kitchen_providers.dart:360`); Home has later-phase additions not signed off against the prototype; hand-written client instead of OpenAPI-generated.

## Architecture suggestions
Demo as a flavour with its own ProviderScope overrides, delete Fallback* repositories; one ApiClient with interceptors (auth, request id, Accept-Language, sealed AppError mapping); drift for cache + outbox with one SyncService; clock/householdNow provider with timezone; startup state machine as GoRouter.redirect with refreshListenable.

## Strengths
Copy fidelity (script diff found no missing visible strings); consistent reduce-motion; correct ticker/controller disposal; If-Match version chaining in replay; bundled Devanagari; clean repository seams; 211 meaningful demo-path tests.
